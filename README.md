# DefiQuill

Decoding and processing decentralized financial data in real-time through a cloud-based, auto-scaling platform framework.

The key benefits of using DefiQuill include:

- Decoding and processing decentralized financial
- data in real-time through a
- cloud-based, auto-scaling platform framework

## Technology Stack

- typescript
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DefiQuill.git`
2. `cd DefiQuill`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
